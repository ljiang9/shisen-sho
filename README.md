# 四川省连连看 (shisen-sho)

终端版四国连连看：8×12 牌面，12 种花色各 8 张（96 张牌）。
两张同花色的牌若能用**不超过 3 段折线（最多转弯 2 次）**连起来即可消除，
折线允许绕到棋盘外一圈。全部消除即通关。

## 玩法

- 交互模式：输入 `r1 c1 r2 c2` 连接两张牌，如 `1 2 1 5`；`q` 退出。
- 数字代表花色，`.` 为空位；行列编号从 0 开始。
- 折线最多 3 段（2 次转弯），可借用棋盘外一圈绕行。

## 用法

```bash
python3 -m shisen_sho                 # 人机交互
python3 -m shisen_sho --auto         # 自动求解演示(默认 10 局)
python3 -m shisen_sho --auto --games 20 --seed 7 --verbose
```

## 求解器说明

自动演示用贪心策略：每步从所有可消除对中随机选一对消除。
实测 `seed 42` 10 局全部通关（共消除 480 对），约 12 秒。

## 已知局限

- 求解器只是随机贪心，不做死局预判；运气不好可能剩牌（实测 seed 42 全通关，但未保证 100%）。
- 无图形界面、无存档、无悔棋、无网络对战。
- Python 3.10+，纯标准库。
